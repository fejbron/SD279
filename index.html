Learning objectives

  1. 01Understand fundamental data structures including arrays, lists, stacks, queues, trees, graphs and hash tables
  2. 02Design and implement efficient algorithms for searching, sorting and manipulation of data structures
  3. 03Perform complexity analysis using asymptotic notation (Big-O, Ω, Θ) to compare algorithmic efficiency
  4. 04Apply abstract data type concepts and distinguish between interface and implementation
  5. 05Use mathematical models of data — sets, lists, graphs — to solve computational problems
  6. 06Identify application areas for each data structure and algorithm in real-world software systems
